สิทธิ์เมนูหลัก

กำหนดสิทธิ์ระดับเมนูหลัก แยกจากสิทธิ์ Batch Module

เลือกผู้ใช้

admin
เลือก user ก่อนเพื่อแสดงสิทธิ์เมนูหลัก

กติกาการทำงาน

Program Permission
none
ไม่เห็นเมนู
view
ดูอย่างเดียว
write
ดูและแก้ไข

ชีท user_menu_permissions จะถูกสร้างอัตโนมัติเมื่อเรียก action นี้ครั้งแรก และจะ seed สิทธิ์ write ให้ user ที่ approved อยู่แล้วเฉพาะตอนสร้างชีทครั้งแรกเท่านั้น
